# Active Directory Lab – Setup

This lab simulates a real MSP/hospital/corporate IT environment using a Windows Server Domain Controller.  
It covers the foundational setup required before creating users, groups, or Group Policies.

---

#---Lab Environment Overview

This lab uses a simple but realistic environment:

- **1 Domain Controller (DC01)**
  - Windows Server 2019 or 2022
  - Active Directory Domain Services (AD DS)
  - DNS Server
- **1 Windows 10/11 Client (CLIENT01)**
  - Joined to the domain
  - Used for testing login, GPOs, and permissions
